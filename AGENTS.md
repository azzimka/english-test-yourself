# AGENTS.md — Инструкция и архитектурный контекст для AI-агентов

Документ предназначен для AI-ассистентов и разработчиков, работающих с репозиторием **english-test-yourself**.

---

## 📌 Описание проекта
Telegram-бот и встроенный **Telegram Mini App** для учителя английского языка.  
Бот автоматизирует проведение школьных тестов и олимпиад: учитель загружает материалы (PDF, Word, TXT или текст сообщением), нейросеть Groq структурирует их в тесты, а ученики проходят задания через удобный черно-белый веб-интерфейс прямо внутри Telegram.

---

## 🛠 Технологический стек

* **Язык & Фреймворк:** Python 3.11+, `aiogram 3.31.0` (асинхронный Telegram Bot API).
* **Веб-сервер Mini App:** `aiohttp` (встроенный в процесс бота веб-сервер на порту `8080`).
* **База данных:** SQLite через `aiosqlite` в режиме WAL (`PRAGMA journal_mode = WAL;`). Файл базы: `data/english_bot.db`.
* **AI & NLP:** **Groq API** (`AsyncGroq`), флагманская модель **`openai/gpt-oss-120b`** (фоллбэки: `openai/gpt-oss-20b`, `qwen/qwen3.8-27b`, `llama-3.3-70b-versatile`) со строгим JSON Schema парсингом через Pydantic. Резервный фоллбэк: Gemini API.
* **Документы & Отчетность:** `pypdf` (чтение PDF), `python-docx` (чтение Word), `reportlab` (генерация PDF), `openpyxl` (экспорт в Excel).
* **Фронтенд Mini App:** Чистый HTML5 / CSS3 / Vanilla JS (папка `web/`), стиль Notion / Apple, кастомные анимированные радио-кнопки.
* **Деплой:** Docker & Docker Compose на Oracle Cloud Infrastructure (Ubuntu ARM64, IP: `92.5.182.119`), HTTPS через Cloudflare Tunnel (`cloudflared`).
* **CI/CD:** GitHub Actions (`.github/workflows/deploy.yml`) — автоматический деплой при пуше в ветку `main`.

## 👥 Роли и пользовательские сценарии

### 1. Учитель (Администратор)
* Авторизуется автоматически по списку Telegram ID из `ADMIN_IDS` в `.env`.
* **Создание теста:**
  1. Выбор категории: *Обычный тест* или *Олимпиадный тест*.
  2. Ввод названия теста учителем вручную.
  3. Загрузка файла (PDF, DOCX, TXT или текст заданий сообщением).  
     *(Внимание: Groq API ориентирован на текстовые материалы, анализ фото страниц отключен; при отправке фото или неподдерживаемых файлов бот выдает понятное предупреждение)*.
  4. Нейросеть Groq (`llama-3.3-70b-versatile`) за 1–3 секунды структурирует задания, варианты и ключи.
  5. Предпросмотр с возможностью отредактировать заголовок (`✏️ Изменить название`) и публикация в 1 клик.
* **Управление («📂 Мои тесты»):** переключатель активности 🟢/🔴 (скрыть/показать для учеников), удаление, выгрузка сводной ведомости в Excel.
* **Кабинет учителя («📊 Результаты учеников» — Teacher Mini App):** встроенное веб-приложение для просмотра сданных работ по тестам, детального разбора ответов каждого ученика и кнопки «Подтвердить оценку» / «Утвердить все» в 1 клик.
* **Уведомления:** при каждой сдаче теста учитель получает лаконичное 4-строчное уведомление (ФИО, класс, тест, первичный балл и время) без громоздкой простыни разбора.

### 2. Ученик
* При первом старте проходит быструю одноразовую регистрацию: **ФИО** и **Класс**.
* В меню выбирает «📚 Обычные тесты» или «🏆 Олимпиадные тесты».
* Нажимает **«🚀 Открыть тест (Mini App)»** — тест открывается во встроенном окне Telegram.
* **Важное правило Anti-Cheat:** ученик **НЕ видит свои баллы и правильные ответы**! В конце показывается нейтральное: *«🏁 Работа принята! Ваши ответы переданы учителю на проверку»*. Повторная сдача олимпиад заблокирована.
* **Раздел «📈 Мои результаты»:**
  * До проверки учителем: `⏳ Статус: Сдано на проверку` (без дат и времени).
  * После подтверждения учителем: бот присылает праздничное уведомление, а в результатах отображается утвержденная оценка `8/10 (80%)`.

## ⚠️ Критические правила и архитектурные конвенции

1. **Разметка сообщений в Telegram:**  
   * **СТРОГО использовать HTML (`parse_mode="HTML"`)** и функцию `html.escape()` при выводе текстов вопросов и названий.  
   * **НЕ использовать Markdown!** Задания по английскому языку содержат пропуски видов `_____` (fill-in-the-blank). В Telegram Markdown пять подчеркиваний подряд вызывают фатальный сбой парсера `Bad Request: can't parse entities`.

2. **Выбор модели Groq и масштабируемый парсинг тестов:**  
   * Основная модель: **`openai/gpt-oss-120b`** (или `openai/gpt-oss-20b`). Отрабатывает за 1–3 секунды с высочайшим качеством грамматического разбора.  
   * Фоллбэк модели: `qwen/qwen3.8-27b`, `llama-3.3-70b-versatile` при временной недоступности или квотах.
   * **Масштабируемый парсинг (40–100+ заданий):** Подробная спецификация и архитектура параллельного чанкинга описана в файле [`CHUNKED_PARSER_ARCHITECTURE.md`](CHUNKED_PARSER_ARCHITECTURE.md). Любые тесты большого объёма должны парситься пакетами через `asyncio.gather` с `max_tokens=8192`.

3. **Безопасность Mini App:**  
   * Эндпоинт `GET /api/test` **никогда не должен возвращать поля `correct_answer` и `explanation`** в браузер клиента. Ученики умеют открывать DevTools.

4. **База данных и персистентность:**  
   * База данных лежит в `./data/english_bot.db`. В Docker она примонтирована через том `./data:/app/data`. При обновлениях контейнера база **никогда не стирается**.
   * Всегда используется `PRAGMA journal_mode = WAL;` для предотвращения `database is locked`.

## 🚀 Деплой и обновления

Проект настроен на автоматический деплой через **GitHub Actions**:
```bash
git add .
git commit -m "описание изменений"
git push origin main
```
GitHub Actions подключается по SSH к серверу Oracle, делает `git pull` и `docker compose up -d --build`.
